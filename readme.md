# About Fake Wordle
Fake Wordle is a school project to learn each step in a fullstack web application inspired of the original game of Wordle but with highscore and this about page.

## How it works
You start with selecting the difficulty of the word by choosing word length and if repeating letters are allowed in the word.
Then you guess words and get green letter for correct letter at the right location, yellow letter for correct letter but wrong location and gray letter for incorrect letter.
When you guess the correct word you can see how fast you were and submit it to the local highscore.
